## Plugins inclus

Thème : **NotAnotherAnimeTheme**

**Messages et chat**
- **MessageLogger** : garde les messages supprimés et modifiés
- **TextReplace** : macros /aide, /wipe, /ciao et /mort
- **SilentTyping** : les autres ne voient pas que tu écris
- **PreviewMessage** : aperçu d'un message avant de l'envoyer
- **QuickMention** : bouton pour mentionner l'auteur d'un message
- **ReplyTimestamp** : affiche l'heure du message auquel on répond
- **MessageLatency** : signale les messages arrivés en retard
- **ShowAllMessageButtons** : tous les boutons au survol d'un message
- **ViewRaw** : voir le contenu brut d'un message
- **WhoReacted** : avatars des gens qui ont réagi
- **MentionAvatars** : avatars dans les mentions
- **ValidUser** : corrige les mentions « utilisateur inconnu »
- **iLoveSpam** : affiche les messages marqués comme spam
- **NoTypingAnimation** : enlève l'animation « en train d'écrire »
- **OnePingPerDM** : une seule notification par message privé

**Serveurs et modération**
- **PermissionsViewer** : voir les permissions d'un membre ou d'un salon
- **ShowHiddenChannels** : voir les salons cachés
- **ShowHiddenThings** : affiche les exclusions temporaires, les invitations en pause et la vue modération
- **ShowTimeoutDuration** : durée restante d'une exclusion temporaire
- **ServerInfo** : infos détaillées sur un serveur
- **MemberCount** : nombre de membres
- **ForceOwnerCrown** : couronne du propriétaire toujours affichée
- **AlwaysExpandRoles** : liste des rôles toujours dépliée
- **RoleColorEverywhere** : couleur des rôles partout
- **NewGuildSettings** : réglages par défaut quand tu rejoins un serveur
- **ServerListIndicators** : compteurs dans la liste des serveurs
- **BetterFolders** : dossiers de serveurs en barre latérale
- **ReadAllNotificationsButton** : bouton pour tout marquer comme lu
- **NoOnboardingDelay** : supprime le délai d'attente quand tu rejoins un serveur

**Profils et amis**
- **PlatformIndicators** : montre si quelqu'un est sur PC, mobile ou web
- **ShowConnections** : comptes liés visibles sur le profil
- **MutualGroupDMs** : groupes privés en commun
- **RelationshipNotifier** : prévient quand on te retire d'un serveur, d'un groupe ou de tes amis
- **SortFriendRequests** : demandes d'amis triées, avec leur date
- **PinDMs** : épingler des conversations privées
- **AccountPanelServerProfile** : ton profil de serveur dans le panneau de compte
- **NoSystemBadge** : pas de badge de notification sur l'icône dans la barre des tâches

**Images et médias**
- **ImageZoom** : loupe sur les images
- **ImageLink** : affiche les images des liens
- **ReverseImageSearch** : recherche d'image inversée
- **CopyFileContents** : copier le contenu d'un fichier texte
- **VoiceMessages** : envoyer des messages vocaux
- **VoiceDownload** : télécharger les messages vocaux
- **YoutubeAdblock** : pas de pub dans les vidéos YouTube intégrées
- **FixSpotifyEmbeds** : corrige les lecteurs Spotify intégrés

**Vocal et Spotify**
- **CallTimer** : durée de l'appel
- **VolumeBooster** : volume jusqu'à ×2
- **VoiceChatDoubleClick** : double-clic pour rejoindre un salon vocal
- **GameActivityToggle** : bouton pour masquer ton jeu en cours
- **SpotifyControls** : lecteur Spotify dans Discord
- **SpotifyCrack** : Spotify ne se met plus en pause pendant que tu es en vocal
- **OpenInApp** : les liens Spotify s'ouvrent dans l'appli
- **SecretRingToneEnabler** : sonnerie d'appel cachée

**Nitro**
- **FakeNitro** : emojis et stickers de n'importe quel serveur, et stream en haute qualité (emojis et stickers envoyés sous forme de liens)

**Outils et confort**
- VencordToolbox, Settings, NoTrack (bloque la télémétrie de Discord), CrashHandler, NoDevtoolsWarning, FullSearchContext, SupportHelper, FixDiscordCss, ConcatenatedComponentExtractor
